# Request for Proposal — Credit Operations Review

## Client

DEF Capital, a non-bank lender.

## Background

DEF Capital wants an independent review of its lending operations to find
efficiency and turnaround improvements before a planned scale-up.

## Timeline

The review should be completed in 10 weeks.

## Scope of Work

- Diagnose the current lending process and quantify delay, and recommend a
  redesigned target operating model with an implementation roadmap.
- Benchmark turnaround performance against comparable lenders.

## Deliverables

- Diagnostic report with a quantified opportunity map.
- Target operating model and implementation roadmap.

## Submission Notes

- Proposals in English, PDF, maximum 15 pages.
- One client reference required.
