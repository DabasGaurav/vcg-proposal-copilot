# Request for Proposal — Actuarial AI Transformation

## Client

XYZ Insurance, a life and health insurer.

## Background

XYZ Insurance wants to transform its actuarial function using artificial
intelligence, including AI-driven reserving, automated experience studies, and
machine-learning mortality and morbidity models embedded in the actuarial
control cycle.

## Timeline

The engagement is expected to run for 16 weeks.

## Scope of Work

- Assess the current actuarial operating model and technology.
- Design an AI-enabled target actuarial operating model.
- Prototype a machine-learning reserving model on historical data.
- Define the model governance and validation approach for actuarial AI.

## Deliverables

- Current-state actuarial assessment.
- AI-enabled actuarial target operating model.
- Working machine-learning reserving prototype.
- Actuarial model governance framework.

## Evaluation Criteria

- Mandatory: demonstrated prior experience delivering deep actuarial AI
  transformation for an insurer, including production machine-learning
  reserving models.
- A credible workplan for the 16-week engagement.
- Named team members with actuarial and machine-learning experience.
- A model governance approach appropriate to a regulated actuarial function.

## Procedural Requirements

- Proposals must be submitted in English.
- One client reference for a comparable actuarial engagement must be provided.
