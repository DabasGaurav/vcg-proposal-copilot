# Request for Proposal — Core Banking Platform Replacement Delivery

## Client

Helvetia Retail Bank, a retail bank operating across Europe.

## Background

Helvetia's core banking platform is end-of-life. The bank has already completed
its own diagnostic and does not require further assessment. Helvetia seeks a
partner to deliver the replacement programme: migration execution, data
migration, cutover and post-cutover stabilisation.

## Timeline

The delivery programme runs for 78 weeks.

## Scope of Work

- Execute the core banking platform migration.
- Deliver data migration from the legacy core.
- Plan and run cutover, including rehearsals and rollback.
- Stabilise operations after cutover.
- Decommission the legacy platform.

## Deliverables

- Migration execution plan and delivered migration.
- Data migration results with reconciliation evidence.
- Cutover runbook and executed cutover.
- Post-cutover stabilisation report.
- Legacy decommissioning confirmation.

## Evaluation Criteria

- Mandatory: demonstrated prior experience delivering a completed core banking
  platform replacement for a retail bank.
- Demonstrated prior experience executing a data migration from a legacy core.
- Demonstrated prior experience running a core banking cutover.
- Evidence of a delivered, stabilised core banking platform in production.
- Named team members with core banking migration delivery experience.

## Procedural Requirements

- Proposals must be submitted in English.
- Commercial pricing must be submitted as a separate sealed document.
